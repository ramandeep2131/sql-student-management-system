
# Student Management System

A relational database project designed to store and manage student records, course enrollments, and academic performance using SQL.

## Features
- **Schema Design:** Normalized tables for `Students`, `Courses`, and `Enrollments` with primary and foreign key constraints.
- **Data Integrity:** Cascading operations and relational mapping to maintain accurate records.
- **SQL Queries:** Includes complex multi-table `JOIN` operations, aggregate calculations (`GROUP BY`), and data modification statements (`UPDATE`, `DELETE`).

## File Structure
- `student_management_system.sql` - Contains table definitions, sample data, and analytical SQL queries.

## Usage
Import `student_management_system.sql` into any standard SQL environment (e.g., SQLite, PostgreSQL, or MySQL) to execute the schema and queries.
